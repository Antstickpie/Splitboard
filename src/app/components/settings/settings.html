Which Import Method Should You Use?

⚠️
Important — EveryDollar 500-Transaction Limit: EveryDollar's backend API caps individual searches at ~500 transactions. For 100% data completeness, keep requests to max 1 month per query. Both Splitboard's Proxy and the Console Script automatically slice multi-month ranges into 1-month chunks with &size=1000 so you never miss transactions!

Best for: 1 to 6 months, quick exports, and using Splitboard on the hosted website. Requires zero setup, zero terminal commands, and zero Node dependencies.

  1. Open everydollar.com in your browser where you are already signed in.
  2. Press F12 (or Cmd + Option + I on Mac) to open Developer Tools, then click the Console tab.
  3. Copy the script below, paste it into the console, and press Enter.
  4. Enter your start and end dates when prompted. It automatically queries month-by-month and saves everydollar_...json to your Downloads.
  5. Come back here, expand "📋 Alternative: Paste EveryDollar JSON or Drop File" below, and drop your JSON file!
