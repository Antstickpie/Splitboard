# Splitbunch

Zero-backend client-side financial manager, statement processor, and multi-person expense splitter.

## Features
- **Bank Statement Parser**: Parses PDF, CSV, TSV, XLSX statements from **Deutsche Bank**, **Amazon Visa (Zinia)**, **Amex**, **Revolut**, and **Commerzbank**.
- **Splitter Engine**: 50/50, custom %, exact allocation, 100% self, 100% other, or direct cash transfers with automated net balance settlement.
- **Budget & Analytics**: EveryDollar zero-based monthly budget tracking with planned vs actual category grouping.
- **Privacy & Storage**: 100% client-side LocalStorage + direct Google Drive cloud backup.

## Development
```bash
npm install
npm start
```
